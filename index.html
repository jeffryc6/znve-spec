Zero-Noise Vibe Engineering

Programa con IA sin ruido, sin deuda y sin sorpresas.

Build with AI without noise, debt or surprises.

ZNVE es una metodología abierta que convierte a tu asistente de IA (Claude, Gemini, Copilot, Cursor, DeepSeek, Ollama, OpenRouter o Antigravity) en un ejecutor disciplinado. Primero se diseña un contrato; después la IA escribe solo el código necesario, sin dependencias parásitas, sin logs de relleno y sin errores silenciados.

ZNVE is an open methodology that turns your AI assistant (Claude, Gemini, Copilot, Cursor, DeepSeek, Ollama, OpenRouter or Antigravity) into a disciplined executor. First you design a contract; then the AI writes only the code that is needed, with no parasitic dependencies, no filler logs and no swallowed errors.

01 · El problema01 · The problem

El "vibe coding" es rápido… hasta que deja de serlo

"Vibe coding" is fast… until it isn't

Pedirle código a una IA sin reglas funciona los primeros días. Después aparece la deriva agéntica (agentic drift): el asistente pierde el contexto, inventa arquitectura y arregla un error rompiendo otros tres.

Asking an AI for code without rules works for the first few days. Then agentic drift sets in: the assistant loses context, invents architecture and fixes one bug by breaking three others.

📦 Dependencias parásitas

📦 Parasitic dependencies

Instala axios, lodash o moment para tareas que el lenguaje ya resuelve. Cada paquete es superficie de ataque, peso y deuda de actualización.

It installs axios, lodash or moment for tasks the language already solves. Every package is attack surface, weight and upgrade debt.

🔇 Errores silenciados

🔇 Swallowed errors

Bloques catch {} vacíos y sleep() para "arreglar" condiciones de carrera. El fallo sigue ahí, solo que ahora nadie lo ve.

Empty catch {} blocks and sleep() calls to "fix" race conditions. The bug is still there; now nobody can see it.

📢 Ruido operativo

📢 Operational noise

Logs de "OK" y "Success" en cada petición. En producción, las alertas reales se pierden entre miles de líneas irrelevantes.

"OK" and "Success" logs on every request. In production, real alerts get lost among thousands of irrelevant lines.

🌀 Bucles de reparación

🌀 Repair loops

Sin un contrato, la IA propone mejoras infinitas y cambia estructuras que nadie aprobó. El proyecto nunca se estabiliza.

Without a contract, the AI keeps proposing "improvements" and changes structures nobody approved. The project never stabilizes.

02 · Qué es ZNVE02 · What ZNVE is

Dos axiomas, dos roles y un formato fijo

Two axioms, two roles and a fixed format

Axioma 1 · Diseño pesado, ejecución silenciosa

Axiom 1 · Heavy design, silent execution

"Inteligencia pesada en el diseño; huella casi nula en la ejecución." Todo el razonamiento ocurre antes de programar; lo que llega a producción es mínimo, predecible y fácil de verificar.

"Heavy intelligence in the design; near-zero footprint in execution." All the reasoning happens before coding; what reaches production is minimal, predictable and easy to verify.

Axioma 2 · Ejecución de contratos

Axiom 2 · Contract execution

"La IA no inventa arquitectura; ejecuta contratos deterministas." La forma de los datos, los errores y las dependencias permitidas se deciden y se aprueban antes de escribir código.

"AI does not invent architecture; it executes deterministic contracts." Data shapes, errors and allowed dependencies are decided and approved before any code is written.

👤 Tú: Director de Arquitectura

👤 You: Director of Architecture

Delimitas qué se construye, apruebas los contratos y certificas que el resultado es correcto.

You set the scope, approve the contracts and certify that the result is correct.

🤖 La IA: Ejecutor Táctico

🤖 The AI: Tactical Executor

Produce código que cumple el contrato al 100 %, en un único archivo objetivo (TARGET_FILE) por tarea, sin cambios estructurales no autorizados.

It produces code that fulfils the contract 100%, in a single target file (TARGET_FILE) per task, with no unauthorized structural changes.

8 reglas que el agente aplica siempre

8 rules the agent always applies

1. Anti-Bloat Fence: nada de librerías si la API nativa lo resuelve.Anti-Bloat Fence: no libraries when the native API solves it.
2. Cero ruido: telemetría solo ante anomalías.Zero noise: telemetry only on anomalies.
3. Contrato primero: sin contrato aprobado, no hay código.Contract first: no approved contract, no code.
4. El hilo principal nunca se bloquea.The main thread is never blocked.
5. Nada de SELECT *: proyecciones e índices.No SELECT *: projections and indexes.
6. Prohibidos los catch vacíos y los sleep parche.No empty catch blocks or patch sleep calls.
7. Sin relleno: directo al artefacto técnico.No filler: straight to the technical artifact.
8. Verificación inviolable: no se tocan los tests para obtener verde ni se declara lo no ejecutado.Inviolable verification: tests are never edited to get green and nothing unexecuted is claimed.

04 · Contrato primero04 · Contract first

La IA se detiene cuando el contrato está sólido

The AI stops once the contract is solid

Con /znve-contract la IA recomienda el stack de la plataforma, diseña los DTOs en contracts/ y aplica una lista de chequeo de 4 puntos. Cuando se cumple, emite un criterio de parada y deja de proponer cambios: así se corta el bucle infinito de "mejoras".

With /znve-contract the AI recommends the platform stack, designs the DTOs in contracts/ and applies a 4-point checklist. Once it passes, it emits a stop criterion and stops proposing changes, which breaks the endless "improvement" loop.

✅ Lista de chequeo de solidez

✅ Solidity checklist

1. Estructura invariable: entradas, salidas, entidades y enums tipados.
2. Defensas de frontera: errores explícitos, sin any.
3. Cero dependencias parásitas: solo SDK nativo o runtime aprobado.
4. Filtro de diferimiento: ideas secundarias a contracts/CONTRACT_BACKLOG.md.

1. Invariant structure: typed inputs, outputs, entities and enums.
2. Boundary defenses: explicit errors, no any.
3. Zero parasitic dependencies: native SDK or approved runtime only.
4. Deferral filter: secondary ideas go to contracts/CONTRACT_BACKLOG.md.

🛑 Stop criterion

11 · Preguntas frecuentes11 · FAQ

Preguntas frecuentes

Frequently asked questions

¿Tengo que instalar algo en mi proyecto?

No. ZNVE son instrucciones para tu asistente de IA (una skill, un archivo de reglas o un prompt de sistema). El servidor MCP es opcional y solo lo necesitan agentes autónomos como Antigravity.

¿Sirve solo para TypeScript?

No. Es agnóstico al lenguaje y a la base de datos. La Capa Camaleónica añade reglas específicas para Android, iOS/macOS, Windows, híbridos (Tauri, Flutter, React Native) y Web/Backend.

¿Qué pasa si la IA ignora una regla?

Tú eres el Director de Arquitectura: los 4 bloques y los encabezados fijos de cada comando hacen visible cualquier desvío. Con el servidor MCP, además, herramientas como znve_surgical_write rechazan físicamente un catch vacío.

¿Funciona con mi proyecto actual, no solo con proyectos nuevos?

Sí. El modo 2 (--delta) añade capacidades sin romper contratos, el modo 3 atiende incidentes en producción y el modo 5 rescata código legacy sin tests.

¿Está disponible en inglés?

Esta página, el README y el glosario son bilingües, y las reglas de Cursor están en inglés. El resto de documentos está en español: en modo inglés sus enlaces se abren a través del traductor de Google, y puedes pedirle a cualquier asistente que responda en inglés.

¿Cuál es la licencia?

La especificación y la documentación usan CC BY 4.0. Los protocolos (/protocols) se ofrecen a la vez bajo CC BY 4.0 y MIT. Las herramientas del repositorio, bajo MIT. Detalles en LICENSE.

¿Cómo propongo un cambio?

Mediante una RFC: copia rfcs/0000-template.md, abre un pull request y, si modifica comandos o reglas, cambia znve-auto/master_spec.json. Guía en CONTRIBUTING.md.

Do I need to install anything in my project?

No. ZNVE is a set of instructions for your AI assistant (a skill, a rules file or a system prompt). The MCP server is optional and only needed by autonomous agents such as Antigravity.

Is it only for TypeScript?

No. It is language- and database-agnostic. The Chameleon Layer adds specific rules for Android, iOS/macOS, Windows, hybrid apps (Tauri, Flutter, React Native) and Web/Backend.

What if the AI ignores a rule?

You are the Director of Architecture: the 4 blocks and each command's fixed headers make any drift visible. With the MCP server, tools such as znve_surgical_write also physically reject an empty catch.

Does it work with my existing project, not just new ones?

Yes. Mode 2 (--delta) adds features without breaking contracts, mode 3 handles production incidents and mode 5 rescues untested legacy code.

Is ZNVE available in English?

This page, the README and the glossary are bilingual, and the Cursor rules are in English. The other documents are in Spanish; in English mode their links open through Google Translate, and you can ask any assistant to reply in English.

What is the license?

The specification and documentation use CC BY 4.0. The protocols (/protocols) are offered under both CC BY 4.0 and MIT. Repository tooling is MIT. Details in LICENSE.

How do I propose a change?

Through an RFC: copy rfcs/0000-template.md, open a pull request and, if it changes commands or rules, edit znve-auto/master_spec.json. Guide in CONTRIBUTING.md.
